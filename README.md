# Machine Learning Labs

Laboratories developed as part of the **ISIS2611 Machine Learning** course at _Universidad de Los Andes_.

## Notebook Summaries

### Labs

- **Lab01-HealthcareDataModeling.ipynb**: Explores and cleans healthcare data from AlpesHearth, builds preprocessing pipelines, trains and compares linear regression models, and generates predictions.
- **Lab02-RegularizedPolynomialRegression.ipynb**: Develops polynomial and regularized regression models using validation curves, Ridge and Lasso regression, model comparison, and confidence intervals.
- **Lab03-TrainingAndNutritionPlanClassification.ipynb**: Performs exploratory data analysis and preprocessing, then classifies training and nutrition plans using logistic regression, decision trees, and a multi-label classification approach.
- **Lab04-FlightDelayClustering.ipynb**: Analyzes VuelaAlpes flight data and applies unsupervised clustering with K-Means, Agglomerative Clustering, and DBSCAN to identify passenger groups associated with flight delays.

### Projects

Both projects were executed using Kaggle's CPU environment.

- **Project01-HistoricalDecadeTextClassificationTFIDF.ipynb**: Classifies Spanish historical texts by decade using TF-IDF representations, weighted feature unions, voting classifiers, a specialist classifier, cross-validation, and error analysis.
- **Project02-HistoricalDecadeTextClassificationTransformerEnsemble.ipynb**: Extends historical-decade text classification with TF-IDF, RoBERTa-BNE/BERTIN transformers, Spanish historical stylistic features, data augmentation, grouped cross-validation, and ensemble optimization.
